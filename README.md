# OpenCV Face Overlay System

## Overview
The OpenCV Face Overlay System is a computer vision project developed using Python and OpenCV. It focuses on detecting human faces in images and overlaying accessories such as sunglasses using classical image processing techniques.

This project demonstrates how methods like Region of Interest (ROI) extraction, masking, and alpha blending can be used to achieve realistic image augmentation without relying on machine learning or deep learning models.

It is a simple and practical project designed for beginners to understand core computer vision concepts through hands-on implementation.

## Features

- Detects faces in input images  
- Automatically places sunglasses on detected faces  
- Supports transparent PNG images (alpha channel)  
- Dynamically resizes overlay based on face dimensions  
- Uses masking and alpha blending for realistic output  
- Works effectively with passport-size and standard images  
- Easy to modify with different overlay styles
